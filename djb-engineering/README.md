# DJB Engineering

[Public demo](https://djb-engineering-demo.niall783.chatgpt.site) · [Original website](https://djbengineeringni.co.uk/)

Independent, uncommissioned modern replacement demo by Niall O’Rourke. The existing website is unaffected. 30 complete static pages, with Project Blueprint taste-principles 1.1.0 and copy-style applied. Visitor pages have no demo banners or photo provenance notes.

## Run and edit

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. No installation, build step, database or API key is required. Edit the HTML for content, style.css for the design and script.js for behaviour. site-content.json retains authoring content; changing it alone does not regenerate HTML.

## Enquiries

Forms prepare a message locally for the visitor to review and open in their email app, or copy. They do not submit or store enquiries. Telephone, maps and social links use their respective external services. No booking or payment is implemented.

## Business-specific notes

Includes gates, railings, stairs, balconies, dog runs and fabrication. Official Facebook is linked; the original generic Instagram homepage and obsolete Google+ link are omitted. No customer testimonials or response-time promises are invented.
