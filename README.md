## Run a concept locally

These sites use plain HTML, CSS and JavaScript. No package installation, build step, database or API key is needed.

```sh
cd shimna-travel
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser. Keep the server running while viewing.

## Add another concept

Create a folder with a descriptive lowercase name, add its files and a README, then add a row to the table above. Keep each site's assets inside its folder. Never commit credentials, environment files or private client material.

## Publishing

This repository shares source code. Pushing here does not automatically update the OpenAI Sites preview. The existing preview is managed separately.
