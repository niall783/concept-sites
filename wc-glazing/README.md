# W & C Glazing

[Public website](https://wc-glazing-demo.niall783.chatgpt.site) · [Original website](https://wcglazing.com/)

Independent uncommissioned modern replacement demo by Niall O’Rourke. The original website is unaffected. 19 complete static pages following Project Blueprint taste-principles1.1.0 and copy-style guidance. No demo banners or source-photo notes appear in the visitor pages, as requested.

## Run locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. No package installation, build step, database or API key. Edit HTML for copy, style.css for design, script.js for navigation, filters and enquiry drafts. site-content.json preserves the authoring content; editing it alone does not regenerate HTML.
